## 2. 교육 과정 개요

### 배경 및 목적 (Obsidian 메모 기준)

CI 과정은 LG Display **PL급 R&D 연구개발직**을 대상으로 합니다.

- **목적**: 엔지니어가 설계를 넘어 **제품 전체의 원가와 수익성을 책임지는 관점** 갖기
- **메시지**: 원가 절감 부담이 아닌 **"우리가 기술로 회사를 책임진다"는 자부심** 고취
- **타깃**: 중형 개발 그룹(~60명) + Auto(~40명) 우선 → 대형 개발 → SC 순 확장
- **제조 부문**: 당장 진행 안 함 (동진님과 추가 조율 예정)

### 과정 구성 (3 모듈)

| 모듈 | 주제 | 담당 강사 | 특이사항 |
|------|------|-----------|----------|
| Module 1 | 마인드셋 및 위기 인식 | 최기성 | 대본이 길어 과감히 축소 필요. 관찰자 역할 중요 |
| Module 2 | 원가 수익성 케이스 스터디 | 박지영 | 날카로운 성향, 설득 필요. 뼈대만 있어 살 붙이기 작업 중 |
| Module 3 | 웹 기반 원가 시뮬레이션 | 남수미 (운영 리드) | 재경 부서 출신, 이해도 높아 시뮬레이션 운영 원활 |

**현장 운영 지원**: 현이님 전담  
**리더(병호님)**: 딜리버리(전달력) 과정에서 문제·불만 없도록 운영하는 것이 핵심

### 영상 자료

- **오프닝 영상**: 2분 10초, 컷 편집(근만님) → 자막 추가(상율님)
- **양치기 소년 영상**: 위기에 무덤덤해진 내부 조직 환기용 (사용 합의 완료)
- **경찰 아들 영상**: 집중도 깰 수 있어 **쉬는 시간에만 틀거나 제거**
- **CEO 엔딩 영상**: 공수·보고 절차 부담으로 **최종 취소**

## 3. 시뮬레이션 (Module 3) 개요

### 무엇을 하는 도구인가

LG Display 생산 현장 CI 과정 교육생이 **개발원가 계산 로직**을 손으로 익히는 학습 게임입니다.

- 기존: 엑셀 노란 셀에 답 입력 → 채점
- 현재: 웹 기반 워크시트 + 실시간 타임어택 게임 + 팀 경쟁
- 보안: 실제 로직은 압축·단순화된 뼈대 사용. **교육 차수에만 URL 오픈**, 종료 후 차단

### 게임 구조

- **4 라운드 × 10분 캡** 타임어택
- **4개 케이스** (원가 변동 메커니즘별):

| 케이스 ID | 주제 |
|-----------|------|
| `01-loading` | Loading율 변동 (가동률) |
| `04-material-yield` | 재료비 절감 vs 수율 하락 |
| `05-cuts-mask` | 면취수 · Mask 복합 효과 |
| `06-tact-investment` | Tact 지연 + 투자비 |

- **개인 순위**: 4 라운드 풀이 시간 합산 1·2·3등
- **팀 순위**: 팀에서 가장 늦은 조원 시간 4 라운드 합산 1·2·3등
- **정답**: O/X만 표시 (숫자 미노출)
- **힌트**: 문제 단위 3단계 (100/70/40/20% 차감, 강사 토글)

## 5. 남은 핵심 작업 (인수자 최우선)

### 🚨 1순위 — DynamoDB 활성화 (1차수 전 필수)

코드는 완성됨. **환경변수 설정 + 테이블 생성**만 하면 됩니다.

```bash
# 1. DynamoDB 테이블 생성 (AWS CLI)
aws dynamodb create-table \
  --table-name cost-sim-rooms \
  --attribute-definitions \
    AttributeName=PK,AttributeType=S \
    AttributeName=SK,AttributeType=S \
  --key-schema \
    AttributeName=PK,KeyType=HASH \
    AttributeName=SK,KeyType=RANGE \
  --billing-mode PAY_PER_REQUEST \
  --region ap-northeast-2

# 2. Amplify 콘솔 → 환경변수 설정
AWS_REGION=ap-northeast-2
DYNAMODB_TABLE_NAME=cost-sim-rooms

# 3. Amplify 재배포 → 자동 적용
```

상세: `projects/cost-sim-v2.1/docs/dynamodb-setup.md`
