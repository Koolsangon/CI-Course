## 2. 프로젝트 개요

### 무엇을 하는 도구인가

LG Display 생산 현장 CI(Cost Innovation) 과정 교육생이 **개발원가 계산 로직**을 손으로 익히는 학습 게임입니다.

- 기존: 엑셀 노란 셀에 답 입력 → 채점
- 현재: 웹 기반 워크시트 + 실시간 타임어택 게임 + 팀 경쟁

### 게임 구조

- **4 라운드 × 10분 캡** 타임어택
- **4개 케이스** (원가 변동 메커니즘별):

| 케이스 ID | 주제 |
|-----------|------|
| `01-loading` | Loading율 변동 (가동률) |
| `04-material-yield` | 재료비 절감 vs 수율 하락 |
| `05-cuts-mask` | 면취수 · Mask 복합 효과 |
| `06-tact-investment` | Tact 지연 + 투자비 |

- **개인 순위**: 4 라운드 풀이 시간 합산 1·2·3등
- **팀 순위**: 팀에서 가장 늦은 조원 시간 4 라운드 합산 1·2·3등
- **정답**: O/X만 표시 (숫자 미노출)
- **힌트**: 문제 단위 3단계 (100/70/40/20% 차감, 강사 토글)

## 4. 남은 핵심 작업 (인수자 최우선)

### 🚨 1순위 — DynamoDB 마이그레이션 (1차수 전 필수)

현재 룸 데이터가 **서버 메모리**에만 저장 → Lambda 재시작 시 게임 데이터 소멸.  
30명 라이브 강의에서는 **DynamoDB 연동이 필수**입니다.

```
파일: lib/room/storage.ts
작업: 내부 in-memory Map → AWS DynamoDB SDK 호출 교체
시그니처 변경 없음 (인터페이스 유지)

DynamoDB 테이블 구조 (예정):
  PK: ROOM#{code}
  SK: META | PLAYER#{id} | ROUND#{N} | ROUND#{N}#PLAYER#{id}

환경변수:
  AWS_REGION, DYNAMODB_TABLE_NAME (Amplify 콘솔)
```

## 6. 강의 운영 방법

### 강의 1회 진행 흐름

| 단계 | 시간 | 작업 |
|------|------|------|
| 사전 준비 | -10분 | `/instructor` 접속 → 새 방 생성 → 코드(4자) 칠판 기재 |
| 설정 | -5분 | 시간 캡 10분, 팀 수 5, 힌트 차감 ON 확인 |
| 학습자 입장 | 0~10분 | 30명 각자 노트북에서 URL 접속 → 코드+이름+팀 입력 |
| 인트로 | 10~25분 | `/intro` → `/menu` 대기 |
| 라운드 1~4 | 25~80분 | 강사 Start 클릭 → 자동 진입 → 10분 캡 → 결과 |
| 종합 발표 | 80~90분 | 강사 End Game → 개인/팀 1·2·3등 자동 표시 |
| 디브리프 | 90~120분 | Sandbox 자유 탐험 + 학습 정리 |

### 강사 화면 주요 기능

- `/instructor` → 새 방 생성
- `/instructor/{코드}` → 설정 패널 / 라운드 컨트롤 / 학습자 현황 대시보드

### Fallback (DynamoDB 미완료 시 Plan B)

1. 워크시트 URL 직접 학습자에게 공유 (`/cases/01-loading` 등)
2. 강사가 스톱워치로 시간 수기 측정
3. 결과 발표는 강사 취합 후 구두 안내

### 🔧 자주 발생하는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| dev server 오류 (clientModules) | HMR 캐시 오염 | `rm -rf .next && npm run dev` |
| Playwright 설치 실패 | 사내망 TLS 차단 | 시스템 Chrome 자동 사용 (설정 완료) |
| 라이브 룸 데이터 사라짐 | in-memory 저장소 | DynamoDB 마이그 필요 (Task #1) |
| 사내 노트북 URL 접근 불가 | 방화벽 차단 | `*.amplifyapp.com` 화이트리스트 요청 |

### 📌 변경하면 안 되는 영역

- `lib/cost-engine/engine.ts` + `presets.ts` + `__fixtures__/`
- `components/CostTree/` 시각화
- `content/problems/*.json`의 Reflect 자유 응답
