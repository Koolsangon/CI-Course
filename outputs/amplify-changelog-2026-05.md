## 2. 신규 기능 (사용자 체감 변화)

### 2.1 게임형 인트로 시퀀스
첫 방문자는 랜딩 카드 진입 전 약 60~90초의 온보딩 내러티브를 본 후 본 화면으로 들어갑니다.
- **TitleScreen**: 부제 "파트리더(책임)" 정렬, LG-red 액센트
- **6-beat 다이얼로그**: 박선행 그룹장(멘토) → 강지수 팀장(동료) → 본인(나) 선택 → 미션 브리프 → 페이드
- **3-슬롯 캐릭터 슬롯** (manager · 나 · lead): 활성 발화자 글로우 효과
- **localStorage seen-flag**: 재방문 시 자동 스킵, 랜딩의 *"인트로 다시 보기"* 버튼으로 재생 가능
- **접근성**: ESC/Skip 상시, `prefers-reduced-motion` 존중, 신규 npm 의존성 없음 (framer-motion + lucide-react 재사용)
- **타깃 변경**: 신입사원 시나리오 → **책임급(파트리더) 시나리오**로 재집필 (`자네` 호칭 제거, 1인칭 `나`)

### 2.2 AI Socratic Coach — **양대 코치 체제 (워크시트 + 샌드박스)**

이번 업데이트로 코치가 학습 모드별로 두 갈래로 분리되었습니다. 둘 다 Gemini 2.5 Flash 기반, 동일 `/api/coach` 라우트(SSE 스트리밍)를 공유하되 `mode` 파라미터로 분기되며 시스템 프롬프트와 컨텍스트가 다릅니다.

#### (a) 워크시트 AI 코치 — `FloatingCoach` *(기존 → 이번 업데이트에서 정상 가동 + 힌트 모달 전면 개편)*
케이스별 워크시트 우측 패널의 채팅 코치입니다. e24fae3에서 도입되었으나 **프로덕션에서는 mock 모드로 폴백**되고 있던 상태였고, 셀 힌트 모달은 정답을 그대로 노출하던 구조였습니다. 이번 버전에서 두 가지 모두 해소.
- **프로덕션 정상 가동 복구**: 런타임/환경변수 픽스(§3 참조) 후 마스터 배포에서 실제 Gemini 응답 확인 — Socratic 질문이 스트리밍으로 출력됨
- **시스템 프롬프트 모듈화**: `buildSystemPrompt`로 분리·이름 정리. 워크시트 코치는 정답 키를 prompt 내에 받지만 *"비교/판정 용도로만 사용, 출력 금지"* 규칙으로 차단
- **컨텍스트 자동 주입**: 학습자가 입력한 셀 답안 + 직전 채점 결과(점수, 정답·오답 셀 ID) + 케이스 단계별 코치 가이드(Hook/Discover/Apply/Reflect) 모두 시스템 프롬프트에 포함
- **셀 힌트 모달 전면 개편 (§2.3)**: 기존에는 모달이 *Reference 값 + Expected Answer + 도출 비율 + 공식*까지 그대로 보여줘 정답 노출 위험이 있었음 → **3단계 점진 공개**로 교체
- **세션 격리**: 문제별 localStorage 키 유지 — 워크시트 코치 대화와 샌드박스 코치 대화 자동 분리
- **타입 리팩터**: `CoachRequestBody`가 `mode`/`answers`/`lastGrade`/`sandbox` 모두 optional이 되어 워크시트 호출자(`FloatingCoach`)가 변경 없이 동작 (back-compat 보장)

#### (b) 샌드박스 AI 코치 — `SandboxCoach` *(신규)*
샌드박스 모드(자유 실험실)의 우측 드로어 코치입니다.
- **호출**: `mode="sandbox"`로 동일 `/api/coach` 호출, 워크시트 코치(`FloatingCoach`)와 충돌 없이 병존
- **컨텍스트**: 현재 케이스 + 라이브 슬라이더 파라미터(Loading/Yields/BOM/Panel·Module 가공비 노무·경비·상각) + 계산 결과(소요재료비/가공비/COM/SGA/COP/영업이익·마진) + **직전 변경분(`lastDelta`)** 자동 주입 — 학습자가 막 움직인 슬라이더를 코치가 인지
- **별도 시스템 프롬프트**: `buildSandboxSystemPrompt`. 자유 실험실에는 **정답 키 자체가 존재하지 않음** — 답을 단정하지 않고 *"지금 화면에서 어떤 슬라이더를 움직이면 직접 확인할 수 있을까요?"* 식 실험 유도가 핵심
- **세션 격리**: `sandbox:${caseId}` 키로 워크시트 대화와 분리

#### (c) 양 코치 공통 원칙
- **정답 비노출**: 워크시트 코치는 prompt 내 정답 키를 출력 금지, 샌드박스 코치는 정답 키 자체가 비주입
- **2-3 문장 한국어 응답**: 따뜻하고 구체적, 도메인 용어 정확 사용 (Loading/COM/COP/BOM/수율/한계이익/손익분기 등)
- **단계별 코치 가이드 활용**: 케이스 정의의 `coach.{hook,discover,apply,reflect}`를 학습자 사고 단계에 맞춰 선택

### 2.3 워크시트 셀 힌트 모달 — **3단계 점진 힌트 + 점수 차감**
워크시트 코치(§2.2-a)의 보조 UI입니다. 셀별 `?` 모달이 더 이상 정답 숫자를 노출하지 않습니다.
- **이전**: 모달이 reference 값·expected answer·도출 비율을 그대로 노출 → 정답 역산 가능
- **현재**: **L1 개념 → L2 메커니즘 → L3 공식(대입 경로까지만)** 으로 점진 공개, 어느 단계도 정답 숫자 미포함
- **점수 가중치**: `HINT_PENALTY = [1.0, 0.7, 0.4, 0.2]` — 정답 셀에만 적용, 오답은 항상 0점
- **GradingPanel 표시**: 원시 정답 수 + 가중 점수 동시 표기 (예: `4.1 / 6 (정답 5/6 · 힌트 차감 −0.9)`)
- **셀 배지**: 열람한 단계 H1/H2/H3 노란 배지로 시각화
- **사전 고지 배너**: 워크시트 상단에 점수 차감 정책 명시, 모달 안에 *"배점 70% → 40%"* 다음 단계 비율 표시
- **케이스 적용**: 01-loading, 04-material-yield, 05-cuts-mask, 06-tact-investment 4종 모두 L1/L2/L3 채움
- **레거시 보존**: 케이스 정의의 기존 `hint` 필드는 **AI 코치 컨텍스트용으로 유지** (모달 표시에서만 분리)

## 3. 크리티컬 버그 픽스 (운영 중 무응답 사례)

이전 배포 버전에서 AI 코치가 **응답하지 않고 목(mock) 모드로 폴백**하는 문제가 있었습니다. 두 단계로 근본 원인을 해소했습니다.

### 3.1 `/api/coach` 런타임 → Node.js (`465ac8d`)
- **증상**: master 브랜치에 `GEMINI_API_KEY`를 넣어도 라우트가 mock으로 떨어짐
- **원인**: Amplify Hosting Compute는 **Next.js Edge Runtime을 미지원** → `process.env`가 엣지 컨텍스트에 전파되지 않음
- **조치**: 라우트 런타임을 `nodejs`로 전환 (GoogleGenAI SDK / ReadableStream / TextEncoder 모두 동작 호환)
- **사이드**: `.gitignore`에 `*_accessKeys.csv`, `.aws/`, `credentials`, `aws-credentials*` 추가하여 자격증명 드롭 방지

### 3.2 `GEMINI_API_KEY` 빌드타임 인라인 (`2853077`)
- **증상**: Node.js 런타임 전환 후에도 SSR Lambda 런타임에 환경 변수 미주입
- **원인**: Amplify는 **브랜치 환경 변수를 빌드 환경에는 전달하지만 SSR Lambda 런타임 프로세스에는 자동 주입하지 않음**
- **조치**: `next.config.js`의 `env` 필드에 `GEMINI_API_KEY` 선언 → Next.js가 빌드타임에 인라인
- **안전성**: 해당 키는 `app/api/coach/route.ts` (서버 전용)에서만 참조되어 클라이언트 번들에 절대 포함되지 않음
- **주의(Directive)**: 향후 **클라이언트 컴포넌트에서 참조되는 API 키는 절대 이 방식으로 추가 금지** — 서버 전용 헬퍼로만 다룰 것
