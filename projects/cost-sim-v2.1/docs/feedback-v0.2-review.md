## 2. 실험실_공통 시트

이미지 3개 (자유실험실 화면 스크린샷) + 셀 텍스트 피드백

### 피드백 항목

1. **파라미터 새로고침 시 빨간 박스 및 점선 제거**
   - 전체 초기화 버튼 클릭 후에도 CostTree 상의 빨간 테두리/점선이 남아있는 문제

2. **파라미터 전체 펼치면 맨 아래 화면 잘림**
   - 모든 그룹을 펼쳤을 때 하단 파라미터가 뷰포트 밖으로 밀려나 잘림

3. **수식 인스펙터 표기 방식 통일**
   - 형식: `기존 {값} → 변경 {값} (증감 {±값})`
   - 예시: `기존 70% → 변경 80% (증감 +10%)`

4. *(항목 4 생략)*

5. **화면 명칭 변경**
   - 파라미터 그룹명, 변수명, 페이지 제목 등 일괄 변경 (상세 내용은 아래 시트 참조)

### 반영 여부
- ✅ **항목 2**: 파라미터 패널 `overflow-y: auto` 스크롤 추가 (완료)
- ✅ **항목 3**: FormulaInspector 표기 형식 통일 (완료)
- ✅ **항목 5**: 그룹명·변수명·페이지 제목 변경 (완료)
- ⚠️ **항목 1**: 파라미터 초기화 시 `lastDelta` 리셋은 반영됐으나, **초기화 직후 빨간 테두리/점선이 즉시 사라지는지** 실제 동작 재확인 필요

> **"원가 계산 워크시트 모든 화면에 이걸로 변경"**
> → 첨부된 새 양식 이미지(`Loading율_0`, `_1`)의 레이아웃으로 Loading율 워크시트 화면 전체를 교체하라는 의미

### 이미지별 상세 내용 (새 양식 레퍼런스)

#### Loading율_0 — 인트로 모달 (새 양식)
```
[Loading 변화 문제]
핵심 수식: 가공비 항목 = 기준값 × (기준Loading ÷ 새Loading)
예) Panel 노무비 = 21.30 × (0.70 ÷ 0.50)

버튼: [건너뛰기]  [다음 →]
```

#### Loading율_1 — 문제 본문 화면 (새 양식)
```
[문제] Loading 변화

상황  고객사 주문 급감으로 설비 Loading(가동률)이 70%에서 50%로 떨어졌습니다.

[과제] 가공비 각 항목이 어떻게 변하는지 계산하세요.

[공식] 가공비 = 기준값 × (기준 Loading ÷ 새 Loading)
```

#### Loading율_2 — 힌트 모달 (배점 구조 확인용)
```
[단계별 힌트 — Loading 변화]

점수 안내:
힌트는 단계가 올라갈수록 더 구체적으로 알려주는 대신,
정답을 맞혔을 때 "모든 정답 셀"의 배점이 같이 줄어듭니다
(이 문제 전체에 한 단계 적용)
— 0단계 100% → 1단계 70% → 2단계 40% → 3단계 20%

현재 이 문제의 배점: 20% — 3단계 (공식)

1단계 — 개념
이 셀은 Loading(가동률)에 따라 달라지는 값입니다.
Loading이 줄면 같은 비용을 더 적은 단위에 분담시켜야 한다는 점을 따올려 보세요.

2단계 — 메커니즘
가공비(노무비·경비·상각비)는 고정비 성격이라, 단위당 분담액은 Loading에 반비례합니다.
분자(전체 비용)는 그대로지만 분모(생산량)만 변하는 구조예요.

3단계 — 공식
새 값 = 기준값 × (기준 Loading ÷ 새 Loading).
Reference 탭에서 기준값을 확인한 뒤, 두 Loading의 비율을 곱해보세요.
(정답 숫자는 직접 계산해 주세요.)

모든 힌트를 사용했습니다.    [닫기]
```

#### Loading율_3 — 워크시트 문제 헤더
```
← Loading 변화
```

#### Loading율_4 — 워크시트 목록 헤더
```
← 🗒 원가 계산 워크시트
```

#### Loading율_5 — 하단 안내 텍스트
```
Yellow 셀에 답을 입력한 후 채점 버튼을 누르세요 (소수점 첫째 자리까지).
힌트를 본 셀은 배점이 줄어듭니다.                              [채점하기]

셀 힌트는 3단계로 제공됩니다. 노란 셀의 ? 버튼을 누르면 단계별로 더 구체적인
단서를 볼 수 있어요. 단계가 올라갈수록 그 셀의 정답 배점이 줄어들며
— 100% → 70% → 40% → 20%.
먼저 직접 풀어보고 막힐 때 사용해 주세요.
```

#### Loading율_6 — 계산기 모달
```
[Module 감상비 계산하기]

사용 방법
1. 위 테이블에서 참조할 셀을 클릭하면 해당 값이 수식에 추가됩니다
2. 또는 아래 입력란에 수식을 직접 입력하세요 (예: 21.3*76%, 5+3*2)
3. 연산 버튼(+, -, ×, ÷)으로 사칙연산을 조합하세요
4. 수식이 완성되면 "계산하기"를 눌러 결과를 셀에 입력합니다
예시: Panel 노무비(21.30) × (0.70 ÷ 0.50) > 계산하기 > 29.82

아래 버튼이나 테이블의 셀을 클릭하세요...

식: 21.3÷70%  [지우기]
[+] [-] [×] [÷] [(] [)] [👁] [C]          [계산하기]
```

## ⚠️ v0.2 텍스트박스 피드백 — 정정 및 처리 현황 (2026-05-28)

> **중요 정정**: v0.2 피드백의 본체는 셀 텍스트가 아니라 **스크린샷 위 도형/텍스트박스(drawing shapes)** 에 있었다. 초기 추출(openpyxl)은 셀·이미지만 뽑아 텍스트박스를 누락 → 여러 시트를 "피드백 없음"으로 오분류했다. drawing XML(`xl/drawings/*.xml`)에서 전 시트 텍스트박스를 재추출해 아래 항목을 도출·처리했다. 위 1~7번 섹션(셀 텍스트 기반)은 불완전하므로 본 섹션이 최종 기준이다.
