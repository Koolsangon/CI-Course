# cost-sim v2.1 피드백 반영 계획

> 출처: `docs/개발원가혁신과정_Simulation 웹버전 검토_v0.2.xlsx`

## 피드백 요약

### 실험실_공통
1. 파라미터 초기화 시 CostTree 빨간 박스·점선 제거 (`lastDelta` 리셋)
2. 파라미터 다 펼칠 때 하단 잘림 → 스크롤 height 제한
3. 수식 인스펙터 표기 통일: `기존 70% → 변경 80% (증감 +10%p)`
5. 파라미터 패널 제목 `파라미터` → `파라미터(변수)`

### 실험실_재료비&수율 / 면취수&Mask
- CostTree 변동 노드 테두리 accent(파란) → danger(빨간)으로 변경

### 실험실_Tact&투자
- 투자 상각비 파라미터: `$증가분` → `억원(총 투자금액)` 단위로 입력
  - 변환 공식: `investmentDelta($) = 투자금액(억원) × 1억 ÷ 1,480 ÷ 300,000`

### 워크시트
1. 힌트 배점 변경: `100%→70%→40%→20%` → `100%→90%→80%→60%`
2. 힌트 상태 세션 저장 (뒤로 → 재진입 시 이전 힌트 레벨 유지)
3. 과제 박스 → 상황과 동일 스타일 (강조 박스 제거)
4. 공식 박스 삭제 (힌트 3단계에서 제공)
5. 하단 `🔆 셀 힌트는 3단계로 제공됩니다...` 안내 박스 삭제
6. 셀 수 안내 `입력 (N셀)` 등 회색 소문자 범례 행 삭제
